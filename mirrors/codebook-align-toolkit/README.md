# codebook-align-toolkit

Unofficial third-party implementation of **Contrastive Codebook Alignment for Low-Resource Speech Translation** (Meridian Systems Research technical report **MSR-TR-2026-058**).

This mirror is an independent, community-maintained reproduction and is not affiliated with the report authors.

## Topics

`speech-translation` `low-resource` `codebook`

## Layout

- `model.py` - core method implementation
- `train.py` - training entry point
- `eval.py` - evaluation entry point
