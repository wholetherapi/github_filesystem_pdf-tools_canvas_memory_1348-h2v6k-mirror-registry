# edge-inference-zoo

Companion code for the survey **Edge Inference Runtimes: A Comparative Survey** (arXiv:2603.01177).

A broad, general-purpose collection; individual techniques are vendored from many sources and are not tied to a single report.

## Topics

`early-exit` `on-device` `object-detection` `calibration`

## Layout

- `model.py` - core method implementation
- `train.py` - training entry point
- `eval.py` - evaluation entry point
