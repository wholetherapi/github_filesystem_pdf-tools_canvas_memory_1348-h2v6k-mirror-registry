# MSR Sprint Code Mirrors

Meridian Systems Research keeps read-only mirrors of third-party repositories that may be relevant to current reproduction sprints. Each mirror is stored in its own directory under `mirrors/`, together with a `README.md` describing the upstream project it mirrors.

The authoritative catalogue is `catalog.json` in this repository. Each entry records the mirror path, the upstream project, the upstream popularity snapshot, the primary language, the mirror date and a short topical summary.

Popularity snapshots are taken at mirror time and are not updated automatically.
